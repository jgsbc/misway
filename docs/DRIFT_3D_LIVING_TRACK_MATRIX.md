## 0. Règles de lecture

Chaque track est décrite par six éléments obligatoires :

1. **vérité émotionnelle** — ce que le morceau raconte réellement ;
2. **anomalie centrale** — la règle ordinaire cassée ;
3. **situation signature** — l’événement que le visiteur retient ;
4. **objet diffuseur** — la surface ou l’objet qui porte l’image, le texte, la mémoire ou la transformation ;
5. **interaction cachée** — le comportement optionnel qui récompense la curiosité ;
6. **réaction musicale** — la manière dont la structure du morceau transforme la scène.

Une track ne doit pas recevoir plusieurs anomalies concurrentes.

### Niveaux de folie

- **1 — fissure** : détail discret ;
- **2 — contamination** : plusieurs éléments répondent ;
- **3 — situation** : événement impossible local ;
- **4 — bascule** : la zone entière change temporairement ;
- **5 — monde intérieur** : perception, espace ou temps deviennent instables.

### Priorités

- **V1** : vertical slice ;
- **P1** : développement immédiatement après preuve du socle ;
- **P2** : deuxième vague ;
- **P3** : nécessite une brique spécifique ou une validation artistique complémentaire.

# 6. Synthèse des trois vertical slices

## 6.1 EUX GAINENT

### Objectif

Prouver qu’un landmark existant peut devenir acteur, diffuseur, instrument, anomalie et satire sociale.

### État initial

- salle fixe ;
- trois silhouettes en répétition ;
- bandeau fluorescent ;
- compteurs sportifs ;
- circulation froide ;
- animation modeste.

### Déclenchement

1. morceau lancé explicitement ;
2. véhicule dans la zone ;
3. cue `drop` ;
4. aucun autre événement signature actif.

### Séquence

1. les gestes deviennent parfaitement synchrones ;
2. les compteurs progressent trop vite ;
3. les statistiques changent de nature ;
4. les silhouettes s’arrêtent ;
5. les tapis continuent ;
6. le bâtiment glisse lentement ;
7. message bref : `OBJECTIF DÉPLACÉ` ;
8. retour ou léger décalage jusqu’à la sortie.

### Contraintes

- déplacement faible ;
- pas de robot littéral ;
- pas de texte explicatif ;
- aucun blocage ;
- pas de simulation lourde ;

# 8. Critère global d’acceptation

La matrice est correctement mise en œuvre lorsqu’un visiteur peut traverser Drift et sentir que :

- les ères appartiennent au même monde ;
- chaque morceau possède une idée propre ;
- les objets ne sont pas de simples accessoires ;
- le graphisme apparaît depuis la matière ;
- la musique transforme réellement l’espace ;
- l’humour révèle une vérité ;
- la reconstruction finale n’efface pas les traces du trajet.
