# 1. Déclaration artistique

## 1.1 North Star

Drift est un **road movie musical interactif** dans lequel un monde crédible est progressivement contaminé par l’imaginaire MISWAY.

Le visiteur ne traverse pas un catalogue illustré. Il traverse une mémoire, un système social, des désirs, des routines, des choix, des blessures, des reconstructions et des formes de liberté.

Le monde doit être drôle sans devenir léger, étrange sans devenir gratuit, graphique sans devenir décoratif, réaliste sans devenir banal.

## 1.2 Formule fondatrice

> **Tout paraît normal jusqu’à ce qu’un détail révèle que la logique du monde est fausse.**

Exemples :

- une salle de sport est déplacée par ses propres tapis de course ;
- une publicité poursuit la foule qui essaie de lui échapper ;
- un rond-point refuse toute sortie vers un lieu utile ;
- une fenêtre travaille pendant que son occupant dort ;
- les panneaux d’Overthink deviennent plus nombreux quand le joueur ralentit ;
- les vagues d’ÉTÉÉAOOÉTÉ rejouent des fragments de mémoire ;
- un miroir conserve une trajectoire que le joueur pensait avoir quittée.

## 1.3 Promesse visiteur

En dix secondes, Drift doit paraître singulier, cinématographique, musical, vivant et légèrement insolent.

En dix minutes, le visiteur doit comprendre que :

- chaque morceau possède un monde ;
- les objets ont une seconde fonction ;
- le décor observe et répond ;
- la route raconte une transformation ;
- MISWAY a un point de vue sur le travail, la liberté, la norme, le corps, la mémoire et la reconstruction.

# 2. Matière première MISWAY

## 2.1 Ce qui rend le projet distinctif

L’univers ne doit pas être construit comme le portfolio d’un graphiste abstrait ou le décor d’un jeu générique.

Sa matière vient d’un profil hybride :

- musicien et constructeur ;
- créatif et opérateur ;
- entrepreneur et observateur des systèmes ;
- connaisseur du commerce, de l’industrie, de la logistique et du management ;
- attiré par le voyage, la montagne, la vitesse, l’Afrique, la ville, les technologies et les outils ;
- confronté à la fatigue des organisations et à la nécessité de se reconstruire ;
- attaché à la transmission, à la famille, à la liberté et à la création utile.

Cette hybridation est une source majeure de singularité pour MISWAY. Elle permet de traiter l’absurdité contemporaine depuis l’intérieur, avec précision, et non comme une posture esthétique.

## 2.2 Tensions fondatrices

| Tension | Traduction dans Drift |
|---|---|
| compétence / absurdité | des systèmes techniquement parfaits accomplissent une fonction inutile |
| performance / sens | les compteurs progressent pendant que les personnes s’épuisent |
| contrôle / liberté | les routes officielles enferment ; les chemins secondaires libèrent |
| machine / corps | les outils reproduisent, mesurent ou commandent les gestes humains |
| conformité / singularité | la foule produit de l’identité standardisée ; l’anomalie révèle l’individu |
| sécurité / désir | les zones confortables deviennent anesthésiantes |
| charge / création | la nuit de travail peut être prison ou espace de naissance |
| mémoire / mouvement | avancer modifie les traces mais ne les efface pas |
| fragilité / puissance | les éléments les plus discrets deviennent les plus résistants |
| effondrement / reconstruction | la rupture rend un nouveau signal audible |
| intimité / monde collectif | les paysages sociaux reflètent des conflits intérieurs |
| sérieux / jeu | le jeu révèle ce que le discours rationnel masque |

## 2.3 Règle de transmutation biographique

Drift s’inspire d’une trajectoire réelle, mais ne devient jamais un journal intime littéral.

À éviter :

- données personnelles ;
- détails médicaux ;
- règlements de compte identifiables ;
- caricatures de personnes réelles ;
- exposition familiale ;
- symboles trop explicatifs.

À rechercher :

- archétypes ;
- situations ;
- gestes ;
- systèmes ;
- tensions ;
- métaphores ;
- humour ;
- sensations physiques ;
- traces de vie transformées.

# 3. Positionnement esthétique

## 3.1 Le réalisme contaminé

Le rendu repose sur trois couches.

### Couche A — Ancrage physique

Le monde est lisible et crédible :

- échelle humaine ;
- lumière plausible ;
- matières texturées ;
- météo cohérente ;
- routes praticables ;
- eau, poussière, pluie et vent crédibles ;
- silhouettes reconnaissables ;
- spatialisation sonore.

### Couche B — Contamination graphique

Le réel est piraté par :

- aplats sérigraphiques ;
- trames d’impression ;
- affiches lacérées ;
- collages ;
- pochoirs ;
- graffitis évolutifs ;
- typographie diégétique ;
- anamorphoses ;
- ombres impossibles ;
- écrans analogiques ;
- reflets édités ;
- décalages de couches CMJN ;
- pictogrammes administratifs détournés ;
- marques peintes ou projetées ;
- changements d’échelle ponctuels.

### Couche C — Événement impossible

Un élément casse brièvement la règle du monde :

- un bâtiment se déplace ;
- une ombre agit seule ;
- les panneaux se multiplient ;
- la pluie devient une trame d’encre ;
- une route fantôme apparaît ;
- les vagues impriment une mémoire ;
- les objets cessent de servir les humains.

### Proportion de référence

- 70 % monde crédible ;
- 20 % contamination graphique ;
- 10 % impossible.

Cette proportion évolue selon les ères.

## 3.2 Influences traduites, jamais copiées

Les influences ne sont pas des styles à imiter mais des fonctions à extraire.

### Cinéma urbain et cinétique

À retenir :

- silhouettes fortes ;
- villes comme personnages ;
- mouvement lisible ;
- contrastes d’échelles ;
- accessoires mémorables ;
- humour au milieu du spectaculaire.

À éviter :

- imitation de décors de films ;
- science-fiction générique ;
- citations reconnaissables.

### Culture graphique musicale

À retenir :

- irrévérence ;
- image-logo ;
- typographie assumée ;
- brutalité et chic ;
- objets ordinaires rendus iconiques ;
- rythme visuel.

À éviter :

- pastiche de labels ;
- copie de mascottes ;
- accumulation de stickers sans fonction.

### Pop art, abstraction, art moderne, graffiti

À retenir :

- répétition ;
- détournement ;
- fragmentation ;
- couleur franche ;
- changement d’échelle ;
- collision entre culture populaire et installation artistique ;
- gestes visibles ;
- imperfections d’impression ;
- surfaces urbaines comme médias.

À éviter :

- musée à ciel ouvert ;
- références gratuites ;
- citations d’œuvres ;
- pseudo-graffiti aléatoire.

# 4. Ton général

## 4.1 Les cinq coordonnées

Chaque scène doit être évaluée sur cinq axes :

1. **Lisibilité** — je comprends le lieu avant d’interpréter son symbole.
2. **Singularité** — un screenshot ne pourrait pas appartenir à un autre projet.
3. **Intelligence** — l’anomalie révèle une tension réelle.
4. **Vie** — quelque chose se passe même quand le joueur ne fait rien.
5. **Retenue** — la scène ne montre pas toutes ses idées en même temps.

## 4.2 Humour MISWAY

L’humour est sec, visuel, décalé, parfois tendre et rarement explicatif.

### Familles autorisées

- inversion fonctionnelle ;
- bureaucratie impossible ;
- performance vide ;
- réaction retardée ;
- échelle fausse ;
- répétition excessive ;
- objet rebelle ;
- deadpan ;
- auto-ironie créative.

### Interdits

- meme plaqué ;
- blague textuelle omniprésente ;
- grossièreté comme unique ressort ;
- cynisme total ;
- caricature culturelle ;
- moquerie dirigée vers le bas ;
- gag sans relation avec le morceau.

# 5. Courbe des ères

## 5.1 Entrée — contrôle de normalité

**Fonction :** naissance et autorisation d’entrer dans l’anomalie.
**Réalisme :** 90 %.
**Folie visible :** 10 %.

La grotte reste sombre, minérale et humide. L’absurde apparaît sous forme de dispositif administratif enfoui dans la roche : cabine, portique, tampon, message de sécurité, scanner d’ombre.

Le passage est autorisé parce que le véhicule est déclaré « non conforme ».

## 5.2 Birth Yard — la machine urbaine

**Fonction :** naissance sociale, foule, désir, commerce, cadence.
**Réalisme :** 70 %.
**Contamination :** 20 %.
**Impossible :** 10 %.

La ville est active, opportuniste, contradictoire.

Surfaces dominantes :

- vitrines ;
- affiches ;
- panneaux ;
- fenêtres ;
- passages piétons ;
- métro ;
- écrans ;
- eau des canaux.

## 5.3 Older Shadows — la liberté dangereuse

**Fonction :** mouvement, altitude, voyage, euphorie, choix.
**Réalisme :** 75 %.
**Contamination :** 15 %.
**Impossible :** 10 %.

Les anomalies viennent du vent, de la vitesse, des objets de sport, des routes, des tissus, des ombres et des instruments improvisés.

## 5.4 Vegetative Field — le confort anesthésiant

**Fonction :** routine, travail, quotidien, normalité confortable.
**Réalisme initial :** 85 %.
**Après panne du système :** jusqu’à 55 % de contamination.

Cette ère doit être la plus drôle à froid et la plus inquiétante après réflexion.

Le décor est propre, fonctionnel et poli. Rien n’est manifestement violent. Pourtant tout empêche la vie d’advenir.

## 5.5 New Signal — l’intérieur déborde

**Fonction :** effondrement mental, décision, acceptation, persistance, reconstruction.
**Réalisme :** 45 à 65 % selon les tracks.
**Contamination :** 25 à 40 %.
**Impossible :** 10 à 20 %.

Le ciel, la lumière, les miroirs, les routes, les ombres, l’eau et les souvenirs deviennent acteurs.

La progression ne finit pas dans une explosion d’effets. Elle finit par une simplicité retrouvée.

# 6. Grammaire graphique

## 6.1 Principe

Le graphisme n’est pas une couche UI posée sur le monde.

Il doit être imprimé, peint, gravé, projeté, réfléchi, diffusé, sali, déchiré ou animé par une source du décor.

## 6.2 Surfaces privilégiées

- béton ;
- vitres ;
- affiches ;
- bâches ;
- eau ;
- fumée ;
- nuages bas ;
- carrosserie ;
- panneaux routiers ;
- écrans ;
- sols ;
- murs ;
- ombres ;
- tissus ;
- écume ;
- neige ;
- craie.

## 6.3 Typographie

La typographie est autorisée si elle est diégétique.

Usages :

- consigne ;
- slogan ;
- signalétique ;
- compteur ;
- numéro ;
- avertissement ;
- annotation ;
- fragments de paroles ;
- information dysfonctionnelle.

Règles :

- un message dominant maximum par scène ;
- phrases courtes ;
- éviter les paragraphes ;
- ne jamais écrire tout le sens de la scène ;
- intégrer les mots aux matières et à la perspective.

## 6.4 Couleur

La couleur suit le color script existant.

La contamination utilise :

- une couleur d’accent forte ;
- une couleur secondaire éventuelle ;
- noir, blanc ou matière brute ;
- erreurs de repérage ;
- aplats partiels.

Interdit :

- arc-en-ciel global ;
- saturation uniforme ;
- palette identique sur toutes les tracks ;
- néons sans source ;
- dégradés décoratifs arbitraires.

## 6.5 Motif λ

Le λ peut apparaître par architecture, bifurcation, charpente, ombre, espace négatif, écume, traces, fissures, alignement, cadrage, réflexion ou mouvement de foule.

Il doit être découvert, produit, sculpté, cadré ou activé. Jamais simplement ajouté.

## 6.6 Silhouettes

Chaque track possède :

- un landmark identifiable à distance ;
- un objet signature ;
- une anomalie lisible à moyenne distance ;
- un détail caché lisible à proximité.

# 7. Grammaire des objets vivants

## 7.1 Principe

Tout objet significatif doit posséder au moins deux rôles parmi :

- physique ;
- narratif ;
- médiatique ;
- musical ;
- interactif ;
- mémoriel.

## 7.2 Six familles

### Diffuseur
Supporte une image, une texture, un message, une projection ou une mémoire.

### Acteur
Effectue un geste autonome.

### Instrument
Émet ou transforme un son.

### Déclencheur
Détecte une action du visiteur.

### Mémoire
Conserve une action de la session.

### Anomalie
Modifie temporairement une règle du monde.

## 7.3 Contrat de données conceptuel

```ts
type LivingWorldObject = {
  id: string;
  trackSlug: TrackSlug;
  family:
    | "broadcaster"
    | "actor"
    | "instrument"
    | "trigger"
    | "memory"
    | "anomaly";

  physicalAnchorId: string;
  narrativeRole: string;

  initialState: string;
  activeState?: string;
  resolvedState?: string;

  triggers: Array<{
    type:
      | "proximity"
      | "collision"
      | "stop"
      | "look"
      | "headlights"
      | "speed"
      | "music-cue"
      | "sequence"
      | "return";
    threshold?: number;
    cooldownMs?: number;
  }>;

  audioBinding?: {
    mode: "timeline-cues" | "envelope" | "band-energy" | "none";
    cueSheetId?: string;
    intensity?: number;
  };

  mediaSurface?: {
    kind:
      | "static-texture"
      | "animated-texture"
      | "canvas"
      | "reflection"
      | "decal"
      | "light"
      | "shadow";
    assetId?: string;
  };

  memory?: {
    scope: "local-session";
    key: string;
    maxEntries?: number;
  };

  fallback: {
    reducedMotion: string;
    lowQuality: string;
    noAudio: string;
  };

  reset: {
    type: "distance" | "timer" | "track-exit" | "session";
    value?: number;
  };
};
```

Ce contrat est une direction de conception. Le patch technique doit commencer petit et être prouvé par les vertical slices.

## 7.4 États minimum

Un objet vivant possède au maximum trois états principaux :

1. normal ;
2. contaminé ;
3. résolu ou silencieux.

## 7.5 Déclencheurs prioritaires

1. proximité ;
2. phase musicale ;
3. immobilité ;
4. collision ;
5. orientation ou cadrage ;
6. phares ;
7. retour ;
8. séquence.

# 8. Réactivité musicale

## 8.1 Règle fondamentale

La musique reste déclenchée explicitement par le visiteur.

Aucun effet ne doit contourner la règle d’absence d’autoplay.

## 8.2 Cue sheet dirigé

Le système privilégie un **cue sheet par track** plutôt qu’un analyseur audio générique.

```ts
type TrackVisualCue = {
  atSeconds: number;
  cue:
    | "intro"
    | "pulse"
    | "break"
    | "rise"
    | "drop"
    | "silence"
    | "outro";
  intensity: 0 | 1 | 2 | 3;
  targetGroup?: string;
};
```

L’analyse fréquentielle peut enrichir vibration, eau, souffle et micro-mouvements. Elle ne décide pas seule de la dramaturgie.

## 8.3 Niveaux de réaction

### Niveau 0 — monde silencieux
Vie ambiante légère, aucun événement majeur.

### Niveau 1 — écoute active
Objets plus réactifs et contamination modérée.

### Niveau 2 — cue signature
Anomalie centrale, événement court et mémorable.

### Niveau 3 — écoute suffisante
État secondaire, détail caché ou trace de session.

## 8.4 Silence

Les silences peuvent figer une foule, couper une lumière, révéler un bruit diégétique, laisser un objet seul en mouvement ou rendre visible une mémoire.

# 9. Interaction

## 9.1 Verbes

- conduire ;
- ralentir ;
- s’arrêter ;
- regarder ;
- écouter ;
- éclairer ;
- percuter ;
- choisir ;
- revenir.

Aucune interaction majeure ne doit être ajoutée sans réutiliser ces verbes.

## 9.2 Absence de boutons

Les interactions sont communiquées par le mouvement, le son, la lumière, le cadrage, la proximité, la signalétique diégétique et le HUD existant.

Le bouton audio explicite reste l’exception assumée.

## 9.3 Interaction cachée

Chaque track possède au maximum une interaction cachée forte.

Elle doit être découvrable en attendant, revenant, éclairant, roulant à contre-sens, suivant un rythme, touchant plusieurs objets, cadrant une forme ou écoutant jusqu’à un cue.

## 9.4 Pas de punition

Les situations ne doivent pas bloquer durablement, imposer un grind, déclencher un échec ou exiger une précision incompatible avec mobile.

# 10. Le monde se souvient

## 10.1 Mémoire locale

La mémoire peut retenir :

- nodes visités ;
- morceaux activés ;
- événements vus ;
- objets percutés ;
- trajectoires récentes ;
- ordre de passage ;
- interactions cachées.

Aucun compte n’est requis.

## 10.2 Manifestations

- miroir rejouant une trajectoire ;
- trace transformée ;
- affiche modifiée ;
- lumière reconnaissant le véhicule ;
- vague ramenant un ancien motif ;
- foule évitant le joueur ;
- panneau changeant de ton.

La mémoire doit donner l’impression que le monde a remarqué le visiteur, pas qu’un jeu lui attribue des points.

# 11. Caméra

La caméra peut resserrer, s’abaisser, prendre du retard, dériver, révéler une anamorphose ou s’apaiser.

Elle ne doit pas enlever le contrôle, secouer constamment, imposer une cinématique longue, cacher les corridors ou créer le mal des transports.

Chaque vertical slice possède :

- un plan d’arrivée ;
- un plan de révélation ;
- un plan de réaction musicale ;
- un plan silencieux après l’événement.

---

# 12. Son du monde

Deux couches :

### Diégétique
Trafic, machines, vent, eau, pluie, foule, pas, oiseaux, tissus, électricité.

### Comportementale
Objet qui répond, mini-sample, bruit de procédure, voix fragmentée, son de matière, réponse rythmique.

Règles :

- le son du monde baisse quand le morceau devient dominant ;
- une situation signature possède au maximum deux sons distinctifs ;
- les voix restent brèves et non explicatives ;
- les samples vocaux ne sont ni remplacés ni imités sans intention ;
- le spatial audio sert la localisation.

# 13. Performance et accessibilité

## 13.1 Budgets physiques conservés

- environ 300 draw calls visibles maximum par zone ;
- instancing ;
- atlases ;
- LOD ;
- textures compressées ;
- streaming localisé ;
- qualité desktop et mobile différenciée ;
- audio explicite.

## 13.2 Budgets comportementaux

Par track visible :

- 1 situation signature active maximum ;
- 2 à 4 boucles secondaires ;
- 1 surface média animée dominante maximum ;
- 1 à 2 canvas textures actives proches maximum ;
- événements hors champ désactivés ;
- pas de vidéo lourde par défaut ;
- pas de simulation globale pour un gag local.

## 13.3 Fallbacks

### Reduced motion
Transition d’état, aucune pulsation rapide, aucune caméra forcée.

### Mobile
Textures statiques, moins de silhouettes, pas de réflexion dynamique coûteuse, particules et vagues simplifiées.

### Audio non joué
Scène lisible, aucun événement majeur, vie minimale.

### Audio indisponible
Monde navigable, aucune erreur bloquante.

# 18. Décisions verrouillées

- Drift est un monde musical vivant, pas un catalogue de dioramas.
- Le réalisme reste le substrat, pas la finalité.
- Une track possède une anomalie centrale.
- L’humour révèle les systèmes.
- Les objets possèdent plusieurs fonctions.
- La réactivité musicale est dirigée par des cues.
- Le monde se souvient localement.
- Aucun compte ni scoring n’est nécessaire.
- L’audio reste explicite.
- Le λ est produit par le décor.
- Mobile et reduced motion sont conçus dès le départ.
- Les trois vertical slices précèdent le déploiement sur les 26 tracks.
