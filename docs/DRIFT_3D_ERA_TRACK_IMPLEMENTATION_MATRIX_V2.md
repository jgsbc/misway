# DRIFT 3D — Matrice d'implémentation intégrale des ères et tracks

- **Version :** 2.0
- **Date :** 2026-07-15
- **Statut :** `ACTIVE_PRELIMINARY_CONTRACT_MATRIX`
- **Rôle :** traduire la vision globale en contrats de production préliminaires. Chaque entrée doit être spécialisée par un Identity Contract avant code.

> Aucune entrée de cette matrice n'autorise directement du code.
> Chaque segment exige un Identity Contract spécialisé et accepté.

---

# 0. Champs obligatoires

Chaque segment devra documenter :

- inspiration de base ;
- lieu crédible ;
- vie autonome ;
- anomalie centrale ;
- situation signature ;
- continuité entrante et sortante ;
- systèmes requis ;
- fallback ;
- budgets ;
- do-not-do ;
- cue map ;
- acceptation propriétaire.
