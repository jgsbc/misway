# DRIFT 3D Track Scene Matrix

Companion document for [DRIFT_3D_SET_DESIGN_BLUEPRINT.md](./DRIFT_3D_SET_DESIGN_BLUEPRINT.md)
and the two blueprint SVGs.

This matrix keeps the 26-track topology readable as lived scenes rather than generic era labels.
It is the narrative layer that future 3D primitives should extrude into landmarks.

## Reading rule

Each row translates one track into a concrete scenic cue:

* emotional note: what the track feels like in MISWAY terms;
* 2D motif: the blueprint symbol to draw around the node;
* future 3D landmark cue: what that motif becomes later;
* corridor / no-prop caution: what must stay clear for gameplay;
* confidence: how strongly the motif is grounded in the current notes.
