# WORLD_VISION.md

**Status:** ACTIVE ARTISTIC AUTHORITY  
**Scope:** MISWAY DRIFT and the World Platform that may emerge from it.  
**Rule:** when code/runtime and this document conflict about what is currently delivered, code is runtime truth; this document governs artistic intent.

## North Star

> An album or musical project can become an explorable territory.

Music, geography, memory, motion, atmosphere, narrative events and visual detail are different manifestations of the same work. Tracks do not merely sit inside the world: they progressively inhabit, influence and transform it.

MISWAY is the first real work and the reference implementation. The platform must emerge from solving MISWAY well, never the reverse.

## MISWAY identity

MISWAY DRIFT is an explorable driving world: electronic and organic, automotive, sometimes contemplative, strange, tender, melancholic, funny and occasionally absurd without becoming arbitrary.

The governing visual principle is:

> **Realism first, strangeness second.**

The world must first feel physically credible: coherent scale, geography, terrain, roads, water, materials, light, population and continuity. Anomalies then gain force because they contaminate a believable place.

The target is not literal GTA V or Gran Turismo 7 parity. The target is an unusually crafted web AA automotive experience combining:

- GTA-like geographic continuity and density;
- Gran Turismo-like attention to vehicle, road, materials and light;
- MISWAY's own memory, humor, music, tenderness, melancholy and strangeness.

## Authorial invariants

- 1 world unit is approximately 1 metre.
- Vehicle, road, character, tree, house and prop proportions are never enlarged by globally scaling the world.
- Validated geography, eras, track identities, masterframes, dramaturgies, landmarks, vehicle feel and camera behavior are creative capital, not disposable implementation details.
- A technical migration does not grant permission to redesign the work.
- One major artistic variable changes at a time whenever possible.
- The generator may automate repetition; the artist retains authored overrides and the final word.

## Platform direction

MISWAY itself is not the engine. Under it, reusable capabilities may progressively become a World Platform shared by other projects such as:

- **MISWAY:** driving, contemporary believable world, memory and progressive anomaly;
- **LAMBDA:** walking, paths/forest/countryside, intimacy, silence and contemplation;
- **DOGGOD:** walking/procession, symbolic architecture, ritual, syncretism and transformation.

These worlds should share proven infrastructure without becoming reskins.

The long-term authoring target is approximately:

```text
audio
+ TrackManifest
+ 0–2 hero assets when useful
+ 0–1 narrative signature
= new territory
```

The World Composer is explicitly deferred until MISWAY, the Track Factory, a LAMBDA spike and a small DOGGOD spike prove the abstractions.

## Construction doctrine

```text
PRESERVE
→ REUSE
→ EXTRACT
→ SIMPLIFY
→ INTEGRATE
→ MEASURE
→ ONLY THEN GENERALIZE
```

Prefer, in order:

```text
existing MISWAY code
→ existing MISWAY assets
→ mature open source
→ suitable licensed assets
→ procedural generation
→ new specific code
```

The preferred world model is:

> **hero assets + procedural grammar + authored exceptions**

## Permanent product tests

1. **World:** is it interesting to traverse even when no track is playing?
2. **Era:** can an era be recognized without text or UI?
3. **Track:** does its territory feel native to the world rather than a scene pasted onto it?
4. **MISWAY:** do realism, strangeness, humor, melancholy, tenderness and memory coexist perceptibly?

A technically elegant system that fails these tests is a product failure.
