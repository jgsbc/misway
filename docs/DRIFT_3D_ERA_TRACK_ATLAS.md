## Generic guardrails (stated once, apply to every segment below)

**Global anomaly rule:** one central anomaly per segment; lower-level signals may prepare it, never compete with it.
**Global prohibited interpretations** (repeated verbatim across all 26 tracks in the Implementation Matrix V2; stated once here): no autoplay; no second audio player; no UI substituting for the world; no more than one central anomaly stacked with others; no explanatory lore dialogue; no Realism Bible-breaking abstraction (placeholder primitives, wireframe, Tron/synthwave, unsourced emissive); no claim that unbuild content is already delivered; no premature shared-system extraction ahead of this lot's own gates; no decoration without a narrative/behavioral function.
**Global mobile/fallback identity:** every segment resolves through the standard `SYS-40` Quality Tier (capability scaling, not style change), `SYS-50` reduced-motion contract (fixed poses, discrete state changes, no forced camera/shake), and `SYS-60` no-WebGL narrative path (static panel, shared destinations) unless a track's own Identity Contract specifies something track-local (as EUX GAINENT's fixed pose-per-phase lookup does).
**Global performance envelope:** ≤300 visible draw calls/zone, ≤1.5M triangles, 1K prop/2K hero textures, KTX2, 3-level LOD (`DRIFT_3D_REALISM_BIBLE.md` / `DRIFT_3D_LIVING_WORLD_BIBLE.md` §13.1, identical in both) — stated per segment only where a track has its own measured or track-specific budget note.
**Global owner acceptance frame:** the standard four-stage cycle — Identity Contract (`-00`) → Cue Map or, for Entry, ambient/transition temporal map (`-10`) → Build (`-20`) → Acceptance (`-30`) — per `DRIFT_3D_INTEGRAL_BACKLOG.md` §6. Stated per segment only where status deviates from "not yet started."
