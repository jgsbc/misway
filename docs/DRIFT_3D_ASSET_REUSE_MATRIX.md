# DRIFT 3D — Reuse-First Asset and Systems Matrix

**Status:** `GOVERNANCE RECONCILIATION RECORD` — inventories what exists today and what a future acquisition lot would need to evaluate. Reconciled under `DRIFT-IV-GOV-40`; status taxonomy and evidence-honesty audit reconciled under `DRIFT-IV-GOV-40`'s authorial reconciliation correction.
**No asset downloads occurred to produce this document.** Every "candidate source" below is named because it is a real, well-known asset ecosystem already compatible with this project's stated licensing posture (free/CC0/open, matching the Realism Bible's existing Poly Haven precedent) — never because it has been fetched, inspected, or licence-verified. **No row in this matrix claims an asset is reusable without that verification actually happening in a future lot.** Per this lot's own constraint, a candidate stays `REFERENCE` until a dedicated acquisition lot obtains and records real licence/provenance evidence for the specific file used.

**Status taxonomy (this correction):** `ADOPT` (confirmed, in-repo or licence-verified, usable now or with trivial integration) · `PILOT` (real and working, but needs rework/generalization before it can serve more than its current one-off track) · `REFERENCE` (a named category or pattern, not a verified specific asset — evaluation only, not yet actionable) · `REJECT` (explicitly not to be adopted, with reason). This taxonomy replaces the prior pass's `REUSE-AS-IS`/`ADAPT`/`REFERENCE-ONLY`/`REJECT`/`BUILD-NEW` vocabulary — `REUSE-AS-IS`→`ADOPT`, `ADAPT`→`PILOT`, `REFERENCE-ONLY`→`REFERENCE`, `REJECT`→`REJECT` (unchanged), `BUILD-NEW` retired (it was never actually assigned to any row in the prior pass).

Columns (this correction, full set per the GOV-40 audit requirement): **Exact project/source** · **Exact reusable element** · **Licence & provenance** · **Maintenance/activity** · **Format & dependencies** · **R3F compatibility** · **Technical adaptation cost** · **Beneficiary eras/tracks** · **Status**.

**The owner's instruction for this correction, verbatim intent: "Do not replace missing prior research with generic marketplace suggestions. Mark missing evidence honestly."** This section states plainly what was actually found.

**The one real, confirmed, previously-researched exception:** the 5 Poly Haven CC0 photo material sets already in `public/textures/`, documented in `docs/DECISIONS_LOG.md`'s "24 — Photo-textures CC0" entry and cited by name in `DRIFT_3D_REALISM_BIBLE.md`.
